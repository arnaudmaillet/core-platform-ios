# Custom symbols (#1128)

`Packages/Core/DesignSystem/Sources/DesignSystem/Resources/Symbols.xcassets` holds the app's custom SF Symbols, read through `AppSymbol` (DesignSystem/Tokens). They are generated by `gen.swift` from:
- **Phosphor Icons** 2.1.1 (`@phosphor-icons/core`, MIT, see `PHOSPHOR-LICENSE`): `heart`, `heart-fill`, `chat-teardrop-text`, `chat-teardrop-text-fill`, `arrows-clockwise`, `dots-three`, `export`;
- **the star** (`core.star`, `core.star.fill`), the owner's plump star since #2074. It is traced from the owner's drawings by `star/source/gen-star.swift` (see `star/README.md`), not by `gen.swift`;
- **the crown** (`core.crown`, `core.crown.fill`), the gems' glyph since #2071, traced from the owner's drawings by `crown/source/gen-crown.swift` (see `crown/README.md`). The side-view gem it replaced (#1128) is retired.
- **play and pause** (`core.play.fill`, `core.pause.fill`, `core.play.circle.fill`), the owner's two drawings since #2276, generated by `play-pause/source/gen-play-pause.swift` (see `play-pause/README.md`), and swapped by `PlayPauseGlyph`.

`template-head.svg` is the notes-and-guides part of Apple's symbol template (v4.0, from the SF Symbols app). The generator writes each glyph's margins and its three weight masters into it.

## Regenerate

```bash
npm pack @phosphor-icons/core@2.1.1 && tar -xzf phosphor-icons-core-2.1.1.tgz
swift dev/symbols/gen.swift dev/symbols/template-head.svg package/assets \
  Packages/Core/DesignSystem/Sources/DesignSystem/Resources/Symbols.xcassets /tmp
```

## Known limits
- **One outline, three masters.** Phosphor's thin, regular and bold paths do not share a structure, so they cannot be interpolated. Each template carries the regular outline as its Ultralight, Regular and Black masters, and a glyph draws at one weight whatever the configuration asks. A designer can redraw the masters in the SF Symbols app behind the same names.
- The art is Phosphor's regular weight, scaled 0.4 onto the template's S scale, then fitted per glyph (`fit` in `gen.swift`) so each stands as tall as the system glyph it replaces. It sits 2.2 units below the cap height's middle, so its alignment insets match the system's. A filled glyph is placed in its outline's box, so an off/on swap never jumps. Retouching for the app's identity (corner radius, stroke against SF's medium) is still to do.
- No Draw-On annotations yet. Bounce and replace work on any symbol image.
