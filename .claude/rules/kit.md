# Working in a Kit package

- **Kit is the bottom layer**: models, contracts, pure logic. It depends on nothing of ours above it and imports no UIKit.
- **Value types first**, `Sendable`, with typed identifiers (`TypedID`).
- `CoreContracts/Sources/CoreContracts/Generated/` is generated by `Scripts/generate-contracts.sh` from the pin in `.contracts-pin`. Never edit it by hand.
