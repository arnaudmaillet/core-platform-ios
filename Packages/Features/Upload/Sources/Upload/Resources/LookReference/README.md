# The look reference photograph

`filter-reference.jpg` — 800×800, the picture every look card is drawn from
while the page being edited is a VIDEO. Read through `MediaLookReference`, which
says why a clip's own film is not used.

## Where it comes from

| | |
|---|---|

| Changes | Brought in as an 800×800 JPEG square (170 KB). Nothing beyond that framing and the re-encode. |

⚠️ **CC0 ASKS FOR NOTHING, AND THIS FILE IS HERE ANYWAY.** A public domain
dedication carries no attribution condition, so nothing in the app has to name
the photographer. What a later reader needs is the answer to "may we ship this?"
— and that answer is only cheap while the provenance is written down beside the
bytes. The folder is `.copy`'d whole, so this note travels with the picture into
the bundle rather than drifting away from it in a commit message.

## Why this picture and not another

⚠️ **A LOOK CARD IS A PROMISE, AND IT CAN ONLY BE READ OVER PIXELS THAT CARRY
THE WHOLE SPECTRUM.** Twelve effects and nine presets rendered over one flat
colour draw twelve and nine identical squares. This frame holds turquoise water,
gold grass, deep green pines, a blue sky, a bright limestone mountain and real
shade — so *Noir* reads as noir, *Warm* reads as warm, and a blur has something
to lose. It also holds **no faces and no legible signage**: a card is shown to
every author over their own film, and a stranger's face standing in for it would
be both a privacy question and a distraction from the look it is selling.
